# The Core - Collectivity Management Updates

Public distribution repository for WordPress updates of `The Core - Collectivity Management`.

- Source repository: `webinart/thecore-collectivity-management`
- Distribution branch: `plugin-updates`
- Update channels: `prod`, `beta`

The `plugin-updates` branch is published automatically and contains:
- the installable plugin package contents at branch head
- `prod.json`
- `beta.json`
